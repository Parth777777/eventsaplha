# 1. PRODUCT REQUIREMENTS DOCUMENT (PRD)

## 1.1 Product Vision

EventAlpha is a real-time event intelligence platform that converts unstructured news, filings, and geopolitical developments into quantified stock signals across short-term (1–3 day) and medium-term (20 day) horizons.

---

## 1.2 Core Capabilities

* Event detection (earnings, orders, policy, war, flows)
* NLP-based sentiment + magnitude extraction
* Event → stock + sector mapping
* Dynamic alpha scoring (regime-based weights)
* Geo-intelligence visualization (map layer)
* Real-time alerts (Telegram/Discord)

---

## 1.3 Target Users

* Retail traders (active)
* Semi-pro swing traders
* Finance + tech learners

---

## 1.4 Key Differentiation

* Event-first (not price-first)
* India-first but globally aware
* Dynamic scoring (not static filters)
* Geo-political + macro integration

# 2. SYSTEM DESIGN DOCUMENT

## 2.1 High-Level Architecture

DATA SOURCES → INGESTION → NLP PIPELINE → EVENT ENGINE → SIGNAL ENGINE → API → UI + ALERTS

---

## 2.2 Components

### A. Data Ingestion Layer

* Scrapers (NSE, BSE, news)
* APIs (market + macro)
* Scheduler (cron / Airflow)

### B. NLP Engine

* Entity extraction (company, sector)

* Sentiment scoring

### C. Event Engine

* Normalizes events into schema:

  * type
  * strength
  * timestamp
  * entities

### D. Signal Engine

* Applies weighted scoring
* Uses regime detection
* Outputs expected return + confidence

### E. Storage

* PostgreSQL (structured)
* Redis (real-time cache)

### F. API Layer

* FastAPI endpoints:

  * /events
  * /signals
  * /stocks
  * /alerts

### G. Frontend

* React dashboard
* Real-time feed
* Map visualization

# 6.1 GEO-INTELLIGENCE MAP ENGINE (INTEGRATED)

## Purpose

A spatial intelligence layer that converts global and domestic events into actionable sector and stock-level signals.

---

## Core Pipeline

Event → Geo Tag → Economic Variable → Sector Impact → Stock Mapping → Alpha Score Injection

---

## Geo Tagging Layer

* Extract country/region using NLP
* Map to coordinates (lat/lng)
* Assign event scope:

  * Local (India-specific)
  * Regional (Asia, Middle East)
  * Global

---

## Economic Variable Mapping

Each geography is linked to key economic drivers:

Example:

* Middle East → Crude Oil
* India → Policy, Interest Rates
* China → Manufacturing, Metals

---

## Sector Impact Engine

Translate economic movement into sectoral impact:

* Oil ↑ → Oil & Gas ↑, Aviation ↓, Paint ↓
* Interest Rate ↑ → Banking ↑, NBFC ↓, Real Estate ↓

---

## Stock Mapping Engine

Maps sectors to tradable equities:

* Oil & Gas → ONGC, Oil India
* Aviation → Indigo, SpiceJet

---

## Impact Scoring

Each mapped stock receives:

* Direction (Bullish/Bearish)
* Confidence Score
* Time Horizon (1d / 3d / 20d)

This feeds into:

Alpha Score += Geo Impact Weight × Event Strength

---

## UI Integration (Map Layer)

### Layers

1. Event Layer (color-coded markers)
2. Economic Layer (oil, inflation, policy toggles)
3. Sector Heatmap

### Interaction

Click Event → View:

* Economic impact
* Affected sectors
* Top impacted stocks
* Confidence score

---

## Alerts Integration

Geo-events trigger alerts when:

* High-impact macro events occur
* Sector-wide shifts are detected

Example:
"Middle East conflict → Oil bullish → Aviation bearish"

---

## MVP Scope

* Geo tagging (country-level)
* 5 economic mappings (Oil, Rates, Inflation, Trade, War)
* 10–20 stock mappings
* Basic map UI (Mapbox)
