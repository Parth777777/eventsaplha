API · v1

TickerWave Public Data API

Programmatic access to NSE/BSE markets data — movers, news, events, earnings, IPOs, commodities, and structured stock data. India-focused. Real JSON. Stable contracts.

FREE TIER v1 · BETA Base URL: https://<your-host>/api/v1

Overview

Every endpoint returns JSON in a uniform envelope: { data, count, as_of }. All timestamps are ISO-8601 UTC. All ₹ values are in crore unless stated otherwise. All tickers are NSE symbols, uppercase.

Try it now — paste this in your terminal: 

# Latest India market news, high-impact only
curl "https://<your-host>/api/v1/news?min_quality=high&limit=5"

# Top NSE gainers, sorted descending by % change
curl "https://<your-host>/api/v1/movers?mode=gainers&limit=10"

# Reliance: profile + price + RSI + MA + F-score in one call
curl "https://<your-host>/api/v1/stocks/RELIANCE"

Authentication & rate limits

Free tier: unauthenticated, rate-limited to 60 requests / minute / IP. No API key required.

Future paid tier: will accept an API key via X-API-Key header for higher quotas and longer windows. Free-tier traffic without a key is fine for analysts, students, side-projects, and most quant prototyping.

Caching: hot endpoints (/movers, /news) are server-cached for 30–60 seconds. Heavy fundamentals + financials endpoints are cached for hours. Use the as_of field in every response to detect staleness.

Response envelope

Every successful response follows this shape:

{
  "data": [...],         // or {...} for single-object endpoints
  "count": 12,             // only present when data is a list
  "as_of": "2026-05-18T14:32:05Z"  // server response time
}

Errors

Errors use proper HTTP status codes. Body shape: 

{
  "error": {
    "code": "invalid_ticker",
    "message": "ticker '!!!' contains invalid characters"
  }
}
StatusCodeWhen
400invalid_ticker / invalid_mode / invalid_regionBad query parameters
429rate_limit_exceededFree-tier quota exceeded
500internal_errorUnhandled server error
503db_unavailableDatabase temporarily offline

Top movers

Top NSE stocks by price move, turnover, unusual volume, or volatility.

GET /api/v1/movers
Slices the broad NSE universe by the requested mode and returns the top limit rows. Updated every 5 minutes.
ParamDescription
mode string gainers One of: gainers, losers, volume (by ₹ turnover), unusual (vol multiple ≥ 1.5×), volatile (by absolute % change).
limit int 25 Max rows. 1..100.
min_pct float 0 Minimum absolute % change (for gainers/losers/volatile). 
curl "https://<your-host>/api/v1/movers?mode=gainers&limit=5"

{

      "price": 2156.60,

      "turnover_cr": 1537.7,
      "as_of": "2026-05-18T09:25:00Z"
    }
  ],
  "count": 5,
  "mode": "gainers",
  "as_of": "2026-05-18T14:32:05Z"
}

News

India market news feed with classifier enrichment — every row carries an impact_tier, sentiment, kinds (detected event types), and an optional market_implication.

GET /api/v1/news
The same feed that powers the Newsroom, filterable by category, ticker, freshness, and quality tier. Default: domestic India news, last 24h, meaningful+ quality (noise dropped).
ParamDescription
category stringOne of: corporate, earnings, policy, ipo, geopolitical, commodity, social.
ticker stringFilter to items mentioning this ticker.
min_quality string meaningfulOne of: generic, meaningful, high, critical.
region string domesticdomestic excludes Reuters/Bloomberg/Dow Jones wires.
hours int 24Lookback window. 1..720.
limit int 30Max rows. 1..200.
 
curl "https://<your-host>/api/v1/news?category=earnings&min_quality=high&limit=3"

Composite F-score (0-100) with tier (strong / decent / weak / avoid), narrative label, positives list, red_flags list, and per-component breakdown: valuation (PE, PB) · profitability (ROE, op margin) · growth (revenue, EPS) · leverage (D/E) · cashflow (FCF, OCF) · promoter_pledge · institutional.

Filings archive

Searchable BSE/NSE filings — every quarterly result, order intimation, AGM, and corporate-action PDF we've indexed, with extracted text and parsed numeric fields. Filterable by ticker, type, keyword, and date.

GET /api/v1/filings
Each row carries metadata only (id, ticker, filing_type, title, pdf_url, filed_at, source). Use /filings/{id} to get raw_text_excerpt + parsed numbers.
ParamDescription
ticker stringFilter to one NSE symbol.
type stringOne of: quarterly_result, order_intimation, agm, other.
q stringFull-text search across title + raw_text.
since dateYYYY-MM-DD; lower bound on filed_at.
until dateYYYY-MM-DD; upper bound on filed_at.
limit int 50Max rows. 1..200.
offset int 0Pagination offset.
 
curl "https://<your-host>/api/v1/filings?ticker=RELIANCE&type=quarterly_result"
curl "https://<your-host>/api/v1/filings?q=concall&since=2026-01-01&limit=20"

GET /api/v1/filings/{id}

Historical earnings dates for a ticker, each with the realized T+1 / T+3 / T+5 trading-day price reaction. Pure data — no judgment.

GET /api/v1/earnings/reactions/{ticker}
Each row: earnings_date, base_close, ret_1d_pct, ret_3d_pct, ret_5d_pct, eps_estimate, eps_reported, surprise_pct. Cached 6 hours.
ParamDescription
lookback_quarters int 12Number of past quarters. 4..20.
 
curl "https://<your-host>/api/v1/earnings/reactions/INFY?lookback_quarters=8"

Related events

Events on the same companies, within ± window_days of the anchor event. Each row carries lag_days (negative = before, positive = after) and relation (precedes, follows, concurrent).

GET /api/v1/events/{event_id}/related
Used to surface chains like "QIP 3 days after insider sale, 1 week before the earnings miss". Same-ticker only for now; future versions will add sector linkages.
ParamDescription
window_days int 14Time window each side. 1..60.
limit int 15Max related rows. 1..50.
 
curl "https://<your-host>/api/v1/events/a4f2c.../related?window_days=30"

Smart-money tracker

Longitudinal view of insider + promoter activity for a ticker — SAST disclosures, PIT regulation 7 transactions, pledges, releases. Combines promoter_events + sebi_disclosures into one chronological feed with aggregate stats.

GET /api/v1/smart-money/{ticker}
Response includes data (chronological events), stats (buys, sells, pledges, unique_persons, net_buy_quantity), and people (distinct insider/promoter names involved).
ParamDescription
months int 24Lookback in months. 1..120.
limit int 50Max events. 1..200.
 
curl "https://<your-host>/api/v1/smart-money/RELIANCE?months=36"

Concall transcript search

Full-text search across indexed concall / earnings-call / investor-meet transcripts. The indexer walks the filings table, identifies concall-type rows (by filing_type + title heuristics), fetches the source PDF, extracts text, and splits into paragraphs stored in concall_paragraphs.

GET /api/v1/concalls/search
Each row carries filing_id, ticker, filed_at, paragraph_idx, text, and a snippet (~140 chars windowed around the match). Use /api/v1/filings/{filing_id} for parent filing's pdf_url + extracted numbers.
ParamDescription
q string requiredFree-text query (≥3 chars). Case-insensitive LIKE for now; FTS upgrade tracked.
ticker stringFilter to one NSE symbol.
since dateYYYY-MM-DD; lower bound on filed_at.
limit int 25Max rows. 1..100.
 
curl "https://<your-host>/api/v1/concalls/search?q=capex&limit=10"
curl "https://<your-host>/api/v1/concalls/search?q=guidance&ticker=RELIANCE"
curl "https://<your-host>/api/v1/concalls/search?q=margin%20pressure&since=2026-01-01"

Service-level latency

The data-platform pitch is partly speed. This endpoint exposes our realized alert delivery latency — median, p95, p99 — bucketed by stage (e.g. bse_filing_to_classify, classify_to_alert, alert_to_telegram). Transparency, not promises.

GET /api/v1/sla
ParamDescription
hours int 24Sample window in hours. 1..168.
 
curl "https://<your-host>/api/v1/sla?hours=168"
