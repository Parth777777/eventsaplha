CAGR formula

CAGR = (FV / PV)1/n − 1

Where PV = initial value, FV = final value, n = years. The result is the constant annual rate that would have produced the same end value via pure compounding.

CAGR vs absolute return — why CAGR matters

A 200% absolute return looks great. Over how long? If 4 years, that's 31.6% CAGR (excellent). If 20 years, 5.6% CAGR (worse than an FD). Always ask: over what duration.

FAQ

Can CAGR be negative?

Yes — if FV < PV, CAGR is negative. Means the investment lost value on an annualised basis.

Is CAGR the same as XIRR?

No. CAGR works for a single buy + single sell. XIRR handles multiple buy/sell points (like SIPs). For mutual fund SIPs use XIRR.

What's a good CAGR?

Context-dependent. Equity benchmarks (Nifty 50 long-term) ~12%. FDs ~7%. Real estate ~8%. Anything beating Nifty long-term is exceptional.
